📝 현재 문제점
---

- 사용법이 README의 코드 블록 중심이라, 처음 보는 사람이 "이 도구가 무엇을 해 주는지"를 한눈에 파악하기 어렵습니다.
- 소개와 홍보를 위한 독립 페이지가 없어서, 개인 포트폴리오 대시보드(lab.suhsaechan.kr)에서 연결할 대상이 레포 화면뿐입니다.

🛠️ 해결 방안 / 제안 기능
---

- GitHub Pages(github.io)로 소개 페이지를 구축하고, 레포의 홈페이지 항목과 대시보드 카드에서 이 페이지로 연결합니다.
- 이슈가 생성되거나 제목이 수정되면 브랜치명과 커밋 메시지를 댓글로 자동 생성해 주는 GitHub Action이라는 핵심 가치를 첫 화면에서 보여줍니다.

⚙️ 작업 내용
---

- 페이지 구성: 도구 소개, 빠른 시작(기본, 커스터마이징, Private Repository 예시), 최신 버전과 변경 이력 링크
- Pages 배포 방식(브랜치 또는 Actions)과 소스 위치 결정
- 레포 홈페이지 항목에 github.io 주소 등록
- suh-project-utility 대시보드의 SUH Issue Helper 카드 링크를 새 페이지로 교체
