📝 현재 문제점
---

- 대시보드(`/`)의 서버 통계 섹션이 "전체 N / 오늘 +N" 숫자 타일 10개뿐이라 방문 추이나 어떤 기능이 쓰이는지 한눈에 보이지 않음
- 방문 기록(`PageVisitLog`)과 기능 사용 기록(`FeatureUsageLog`)이 시간과 함께 쌓이고 있지만 기간별 추이, 유입 경로, 인기 페이지, 시간대 분포로는 보여주지 않음
- Task D-Day 섹션은 거의 사용하지 않아 대시보드 공간만 차지함

🛠️ 해결 방안 / 제안 기능
---

- 서버 통계 섹션을 Chart.js 기반 분석 화면으로 개편 (시안 A안)
  - 기간 선택: 7일, 30일, 90일 (기본 30일)
  - 핵심 숫자 카드 4개: 고유 방문자, 페이지뷰, 기능 사용, 챗봇 토큰 (기간 합계, 직전 기간 대비 증감, 스파크라인, 전체 누적)
  - 일별 방문 추이: 고유 방문자와 페이지뷰
  - 많이 쓴 기능 상위 6개
  - 유입 경로 비중: 구글 검색, 네이버 검색, GitHub, 직접 접속, 기타
  - 인기 페이지 상위 5개
  - 요일, 시간대 히트맵
- 비로그인 방문자에게도 공개 (개별 IP, 방문자 식별값, 원본 referrer URL은 노출하지 않고 집계값만 응답)
- 라이트, 다크 테마와 모바일 화면 모두 대응
- Task D-Day 섹션 대시보드에서 제거

⚙️ 작업 내용
---

- 통계 집계 API 추가 (기간별 일별 추이, 기능별 사용, 유입 경로, 인기 페이지, 히트맵) 및 기간별 캐시
- 방문, 기능 사용 기록 시간 컬럼 인덱스 추가
- 대시보드 서버 통계 섹션 화면 개편, Chart.js 연동, 테마 전환 시 차트 색 반영
- Task D-Day 섹션 제거
