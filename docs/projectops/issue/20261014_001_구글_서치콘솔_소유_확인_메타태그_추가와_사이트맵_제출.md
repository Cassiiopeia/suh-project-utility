📝 현재 문제점
---

- lab.suhsaechan.kr 이 구글 서치콘솔에 등록되어 있지 않아 구글 색인 상태와 검색 실적을 볼 수 없고, 사이트맵도 구글에 제출되지 않았습니다.

🛠️ 해결 방안 / 제안 기능
---

- 서치콘솔에 URL 접두어 속성 `https://lab.suhsaechan.kr/` 을 추가하고 HTML 태그 방식으로 소유를 확인합니다.
- 확인 메타태그를 공통 헤더 fragment 에 넣어 모든 페이지 head 에 노출합니다.

⚙️ 작업 내용
---

- `fragments/header.html` 에 `google-site-verification` 메타태그 추가
- 배포 후 운영 홈페이지 head 에 태그가 나오는지 확인
- 서치콘솔에서 확인 클릭 후 `sitemap.xml` 제출
- 검증: 소유 확인 성공, 사이트맵 상태 성공
