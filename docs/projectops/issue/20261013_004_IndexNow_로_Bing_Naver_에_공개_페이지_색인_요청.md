📝 현재 문제점
---

- 새로 정비한 SEO 메타와 사이트맵은 검색엔진이 스스로 다시 방문해야 반영됩니다. 구글 서치콘솔 등록은 사용자 계정이 필요해서 자동화할 수 없고, 그 사이 Bing 과 Naver 등에 변경을 알릴 방법이 없습니다.

🛠️ 해결 방안 / 제안 기능
---

- 계정 없이 쓸 수 있는 IndexNow 프로토콜을 적용합니다. 사이트 루트에 키 파일을 두어 소유를 증명하고, 공개 페이지 URL 목록을 IndexNow 엔드포인트에 제출합니다(Bing, Naver, Yandex 등이 지원).

⚙️ 작업 내용
---

- 키 파일을 `static` 에 추가하고 인증 없이 접근되도록 공개 경로에 등록
- 배포 후 키 파일 응답을 확인하고 공개 페이지 6개의 URL 을 IndexNow 에 제출해 응답 코드를 확인
- 검증: 키 파일 200, 제출 응답 200 또는 202
