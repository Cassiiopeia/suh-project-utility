📝 현재 문제점
---

- lab 서버가 세종대 인증 라이브러리 1.2.7을 사용 중 (최신 1.2.17)
- 세종대 포털은 비밀번호를 여러 번(포털 안내상 약 5회) 틀리면 계정을 잠그고, 잠금은 비밀번호 재설정으로만 풀림
- 세종대 인증 데모 API(`/api/sejong-auth/authenticate`)는 누구나 호출할 수 있어, 남의 학번으로 틀린 비밀번호를 반복하면 그 학생 계정을 잠글 수 있음 (GitHub Pages 데모도 같은 API 사용)
- 1.2.7은 계정 잠금도 "비밀번호 틀림"으로만 알려 줌

🛠️ 해결 방안 / 제안 기능
---

- 라이브러리 1.2.17로 업그레이드 (포털 판정 그대로: `ACCOUNT_LOCKED`, `ACCOUNT_UNAVAILABLE` 추가, 틀린 비밀번호는 추가 요청 없이 즉시 실패)
- 같은 학번이 연속 3번 `AUTHENTICATION_FAILED`면 30분 동안 포털 호출 없이 거절 (`TOO_MANY_ATTEMPTS`), 성공하면 횟수 초기화
- 학번은 해시로만 저장 (Redis)
- `ACCOUNT_LOCKED`면 포털 비밀번호 재설정 주소 안내
- 데모 페이지 에러 코드 표에 새 코드 3개 추가
