📝 현재 문제점
---

- 공통 헤더에 `description`, `canonical`, `og:*`, `twitter:*` 메타가 없어 링크 공유 미리보기가 빈약하고 검색 노출 정보가 부족합니다. 대시보드 탭 제목도 "대시보드-SAECHAN-LAB" 입니다.
- `robots.txt` 와 `sitemap.xml` 이 없고, 로그인이 필요한 내부 페이지에 색인 제외 지정이 없습니다. `<html>` 에 언어 속성이 없습니다.
- Projects 카드는 한 줄 설명뿐이고 기술 스택과 대표 이미지가 없으며, 새 카드 문구가 한국어로 고정돼 영어 화면에서도 한국어로 보입니다.
- 히어로에 행동 유도 버튼이 없고, 비로그인 화면에 "등록된 Task가 없습니다" 빈 상태가 노출됩니다.
- 정적 파일이 압축되지 않고 캐시 정책이 없어 CSS(약 144KB)가 느리게 내려옵니다. 스크롤 등장 애니메이션은 완전 투명에서 시작해 미리보기나 캡처에서 아래쪽이 비어 보입니다.

🛠️ 해결 방안 / 제안 기능
---

- 공통 헤더에 SEO 메타(description, canonical, Open Graph, Twitter Card, robots)를 추가하고, 페이지마다 제목과 설명을 지정합니다. 공개 페이지는 색인, 로그인이 필요한 내부 페이지는 색인 제외로 둡니다. 대시보드에는 Person 구조화 데이터(JSON-LD)를 넣습니다.
- `robots.txt` 와 `sitemap.xml` 을 제공하고, 공유 미리보기용 대표 이미지를 만듭니다. 기준 도메인은 설정값(`site.base-url`)으로 둡니다.
- Projects 카드에 실제 레포와 사이트에서 확인한 설명, 기술 스택, 대표 이미지를 넣고 문구는 다국어(ko/en)로 옮깁니다. 확인되지 않은 역할과 기간은 넣지 않습니다.
- 히어로에 행동 유도 버튼과 수상 배지를 추가하고, 비로그인에서 빈 Task D-Day 는 숨깁니다.
- 응답 압축, 정적 파일 캐시와 콘텐츠 해시 URL, 스크립트 로딩 개선, 등장 애니메이션 완화를 적용합니다.

⚙️ 작업 내용
---

- `header.html` SEO 메타, 페이지별 제목·설명·색인 지정, `<html lang>`
- 사이트 기준 URL 설정과 `robots.txt`, `sitemap.xml` 엔드포인트, 대표 이미지(`og-image`)
- 대시보드 JSON-LD, 히어로 버튼과 수상 배지, 빈 Task D-Day 숨김
- Projects 카드 보강과 다국어 문구
- 압축, 캐시, 리소스 해시, 애니메이션 완화
- 검증: 메타와 구조화 데이터 확인, `robots.txt`/`sitemap.xml` 응답, 압축 헤더, 전 페이지 점검, 프로덕션 확인
