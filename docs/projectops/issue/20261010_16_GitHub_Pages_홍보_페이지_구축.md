📝 현재 문제점
---

- 라이브러리를 체험하는 데모가 suh-project-utility 앱 내부(lab.suhsaechan.kr/sejong-auth)에 있어서, 홍보 페이지가 개인 서버 앱에 묶여 있습니다.
- 레포 홈페이지 항목이 Nexus 저장소 주소라서 라이브러리 소개 화면으로 연결되지 않습니다.

🛠️ 해결 방안 / 제안 기능
---

- GitHub Pages(github.io)로 소개 페이지를 구축하고, 레포 홈페이지 항목과 대시보드 카드에서 이 페이지로 연결합니다.
- 소개 페이지에서 "단 3줄로 세종대학교 포털 인증"이라는 핵심 가치와 빠른 시작을 보여주고, 기존 데모는 링크로 연결합니다.

⚙️ 작업 내용
---

- 페이지 구성: 라이브러리 소개, 주요 기능, 빠른 시작, API 레퍼런스, 설정, 최신 버전
- Pages 배포 방식(브랜치 또는 Actions)과 소스 위치 결정
- 레포 홈페이지 항목에 github.io 주소 등록
- suh-project-utility 대시보드의 sejong-univ-auth 카드 링크를 새 페이지로 교체
- 앱 내부 데모 페이지(/sejong-auth)와 소개 페이지의 역할 분리 방안 결정
