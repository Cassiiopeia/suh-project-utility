📝 현재 문제점
---

- README에 기능과 설치 방법이 있지만 소개 목적의 독립 페이지가 없어, 처음 보는 사람이 결과물을 바로 확인하기 어렵습니다.
- 레포 홈페이지 항목이 Nexus 저장소 주소라서 라이브러리 소개 화면으로 연결되지 않습니다.
- 개인 포트폴리오 대시보드(lab.suhsaechan.kr)에서 연결할 소개 페이지가 없습니다.

🛠️ 해결 방안 / 제안 기능
---

- GitHub Pages(github.io)로 소개 페이지를 구축하고, 레포 홈페이지 항목과 대시보드 카드에서 이 페이지로 연결합니다.
- 랜덤 닉네임 생성(약 96만 조합), 성인용 닉네임(만 19세 이상), 정치인 닉네임 생성이라는 기능을 첫 화면에서 보여줍니다.

⚙️ 작업 내용
---

- 페이지 구성: 라이브러리 소개, 기능 목록, 설치 방법(Gradle, Maven), 기본 사용법, 최신 버전
- Pages 배포 방식(브랜치 또는 Actions)과 소스 위치 결정
- 레포 홈페이지 항목에 github.io 주소 등록
- suh-project-utility 대시보드의 SUH Random Engine 카드 링크를 새 페이지로 교체
