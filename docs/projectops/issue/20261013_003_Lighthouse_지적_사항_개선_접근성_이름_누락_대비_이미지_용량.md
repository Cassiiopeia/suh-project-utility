📝 현재 문제점
---

- 프로덕션 대시보드의 Lighthouse(모바일) 점수가 SEO 100, 권장사항 100 인 반면 접근성 85, 성능 32 입니다.
- 접근성: 아이콘만 있는 헤더 버튼 2개와 푸터 링크 3개에 접근 가능한 이름이 없고, 다크 모드 토글 체크박스에 레이블이 없습니다. 색 대비 부족이 138건인데 대부분은 스크롤 등장 애니메이션(`.reveal`)이 투명도 0.35 에서 시작해 측정 순간 글자가 흐리게 잡힌 것입니다. 일부는 보조 텍스트의 투명도(`/50`, `/60`)가 낮습니다.
- 성능: 헤더 로고(`logo_no_text.png`, 약 333KB)가 32px 로 표시되고, 프로젝트·타임라인 로고와 프로필 사진도 표시 크기보다 훨씬 큽니다. 화면 밖 이미지가 즉시 로드되고, 필수가 아닌 외부 스크립트가 렌더링을 막습니다.

🛠️ 해결 방안 / 제안 기능
---

- 아이콘 버튼과 링크, 토글에 `aria-label` 을 추가합니다.
- 등장 애니메이션은 투명도를 바꾸지 않고 이동만 하도록 바꿉니다. 보조 텍스트 투명도를 올려 대비를 확보합니다.
- 표시 크기에 맞게 이미지를 줄이고, 화면 밖 이미지는 지연 로딩하며, 프로필 사진은 우선 로딩합니다. 렌더링을 막지 않아도 되는 스크립트는 `defer` 로 바꿉니다.

⚙️ 작업 내용
---

- `header.html`, `footer.html`, `dashboard.html` 의 접근성 이름과 텍스트 투명도
- `common.css` 의 `.reveal` 애니메이션
- `static/images` 의 대용량 이미지 축소(파일명 유지)
- 검증: 수정 후 Lighthouse 를 다시 측정해 점수 비교
