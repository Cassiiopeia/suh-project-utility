# 사용하지 않는 CSS 규칙과 다국어 문구 삭제

## 개요

대시보드 개편으로 일부 섹션이 삭제되면서, 그 화면에서만 쓰던 다국어 문구와 CSS 규칙이 참조 없이 남았습니다. 참조가 전혀 없는 것만 골라 삭제했고, 검증 중 발견한 상태 표시 글씨가 묻히던 버그도 함께 고쳤습니다. 배포 커밋은 `deb8597` 입니다.

## 변경 사항

### 다국어 문구 삭제
- `messages_ko.properties`, `messages_en.properties`: 사용처가 없는 키 47개 삭제(`dashboard.project.*`, `dashboard.projects.*`, `dashboard.tool.*`, `dashboard.gpt.*`, `dashboard.aiAssistants.*`). 기본 `messages.properties` 에는 해당 키가 없어 변경 없음

### CSS 삭제
- `static/css/common.css`: 템플릿, JS, Java 어디에서도 쓰이지 않는 규칙 삭제(`.analyzing-dots` 계열, `.analyzing-text`, `.badge-sky`, `.figma-logo`, `.main-title`, `.version-title`, `.version-date`, `.version-row`, `.modal-table-container` 계열), 해당 규칙만 쓰던 `@keyframes analyzingDots` 와 인쇄 규칙의 `.no-print` 삭제

### 버그 수정
- `templates/pages/dashboard.html`: AI 서버 상태 표시 요소에 붙은 `loading` 클래스가 DaisyUI 스피너 마스크(배경색이 글자색)를 적용해 "확인중" 문구가 배경에 묻혔습니다. 상태 플래그 클래스를 `is-checking` 으로 바꾸고 JS 의 `removeClass` 도 함께 변경

## 주요 구현 내용

- 문구 키와 CSS 클래스는 삭제 전에 템플릿, JS, Java 전체에서 참조 여부를 검색했고, 클래스 이름이 문자열로 조립되는 경우가 없는지 확인한 항목만 삭제했습니다.
- 삭제 후 앱에서 `??키??` 형태의 누락 문구가 노출되는지 모든 페이지를 한국어와 영어로 점검했습니다.

## 검증

- 로컬 실제 앱: 13개 페이지 × ko/en 문구 누락 0건(26개 화면), 13개 페이지 × 라이트/다크 × 1280px/390px 52회 점검에서 대비 실패 없음(로컬 Ollama 부재로 인한 `/ai-server` 500 제외)
- 프로덕션 배포 후: CICD-BLUEGREEN 성공, 헬스체크 200, 비로그인과 로그인 모두 카드 13개, 문구 누락 0, 실패 요청 0, 콘솔 에러 0, 비로그인에서 Dev Tools 숨김

## 주의사항

- 이미지 파일처럼 파일 단위로 남은 미사용 자원은 이번 범위에서 삭제하지 않았습니다. 대상은 `tripgetherLogo.png`, `세종말싸미_로고.png`, `sejongBalsamicLogo.png`, `sulGameWiki.png`, `SamCoMoLogo.png`, `bagelLogo.jpeg` 중 참조가 없는 것이며, 삭제 전 사용처 확인이 필요합니다.
- DaisyUI 컴포넌트 이름(`loading`, `badge` 등)을 상태 플래그로 재사용하면 의도하지 않은 스타일이 적용됩니다. 상태 클래스는 별도 이름을 쓰세요.
