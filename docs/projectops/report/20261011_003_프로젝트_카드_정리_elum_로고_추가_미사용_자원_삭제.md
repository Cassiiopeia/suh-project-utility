# 프로젝트 카드 정리, elum 로고 추가, 미사용 자원 삭제

## 개요

대시보드 Projects 를 요청에 맞게 정리했습니다. 프로젝트가 아닌 도구성 카드를 빼고, 카드 순서를 재배치하고, elum 과 Hack the Beat 에 로고를 적용했습니다. 참조가 없어진 이미지와 아이콘 11개를 삭제했고, 검증 중 발견한 통계 스켈레톤이 사라지지 않던 버그와 페이지 중간에 남아 있던 옛 환영 헤더도 정리했습니다. 배포 커밋은 `7c70ed5`(정리)와 `4cbf962`(섹션 순서)입니다.

## 변경 사항

### Projects 카드
- `templates/pages/dashboard.html`: PLANE ACCIDENT FINDER, SUH Issue Helper, Grass Planter, AI 번역기, SUH Random Engine 카드 삭제. Personal Projects 의 GitHub Issue Helper, Custom AI Translator, Grass Planter 카드도 같은 기준으로 삭제
- 카드 순서를 ROM ROM, elum, passQL, Hack the Beat, PickerPicker, ProjectOps, Re: WAVE, sejong-univ-auth 로 재배치
- elum 카드에 앱 로고 적용, Hack the Beat 카드에 구글 로고와 "Google Developers Groups" 표기 적용(수상 문구의 "GDG" 표기도 동일하게 변경)

### 섹션 순서
- `dashboard.html`: Awards 를 About Me 바로 아래로 올리고 Projects 를 그 뒤에 배치(프로필, About Me, Awards, Projects, Timeline, Certifications, Tech Stack)

### 삭제
- `static/images`: 참조가 없는 이미지 10개(`PLANE_ACCIDENT_FINDER_로고`, `ROMROM_글씨_로고`, `SamCoMoLogo`, `Zadanna Square`, `sejongBalsamicLogo`, `sulGameWiki`, `tripgetherLogo`, `로고_세로`, `세종말싸미_로고`, `소만사_로고`)와 `static/icons/figmaLogo.svg` 삭제. 삭제 전 저장소 전체에서 참조 여부를 확인했고, 브라우저가 자동 요청하는 `favicon.ico` 는 유지
- `static/images/elumLogo.png`: elum 레포의 앱 아이콘을 192px 로 줄여 추가
- 옛 환영 헤더("새찬 서버 실험실") 블록과 해당 다국어 문구 삭제

### 버그 수정
- `static/css/common.css`: `.dashboard-card-grid-5` 가 `display: flex` 를 지정해 `hidden` 클래스를 덮어쓰는 바람에 서버 통계 스켈레톤이 실제 카드 위에 계속 남아 있던 문제를 수정

## 검증

- 로컬 실제 앱: 스켈레톤 `display: none`, 보이는 스켈레톤 0개, 카드 순서와 elum 로고(192px)와 구글 아이콘 확인, 깨진 이미지 없음, 환영 헤더 제거 확인
- `hidden` 이 CSS 충돌로 먹히지 않는 요소를 13개 페이지 × 로그인/비로그인에서 전수 탐지해 실제 충돌은 이 한 곳뿐임을 확인(나머지는 `hidden lg:flex` 같은 정상적인 반응형 패턴)
- 프로덕션 배포 후: CICD-BLUEGREEN 성공, 13개 페이지 × 1280px/390px 점검에서 가로 넘침 0건, 스타일시트 정상 로드, 순서와 카드 목록 반영 확인

## 주의사항

- 배포의 Blue-Green 전환 구간에는 짧게 연결이 끊겨 CSS 가 안 와 화면이 깨져 보일 수 있습니다. 배포 직후 확인 시 한 번 더 새로고침하세요. 서버 응답이 전반적으로 1~3초로 느린 점은 이번 범위 밖입니다.
- 삭제한 이미지는 깃 이력에서 복구할 수 있습니다.
- 공개 도구 3종(SUH Issue Helper, SUH Random Engine, sejong-univ-auth)의 GitHub Pages 홍보 페이지는 각 레포 이슈(#5, #13, #16)에서 진행합니다. 대시보드 카드는 sejong-univ-auth 만 남아 있고, 나머지 두 도구 카드는 이번에 삭제했습니다.
