# 아이디어 보따리: 개발 아이디어 키워드 간편 저장

## 개요

"이거 만들어볼까?" 싶은 아이디어를 키워드 한 줄로 바로 적어 두는 개인 저장소를 만들었다. 대시보드에서 Enter 한 번으로 저장하고, `/ideas` 페이지에서 전체를 관리한다.

## 변경 사항

| 구분 | 내용 |
|---|---|
| 새 모듈 | `Suh-Domain-Idea`: `IdeaItem` 엔티티(키워드 200자, 메모, 상태), `IdeaItemRepository`, `IdeaService`, DTO |
| 공통 | `IdeaStatus`(IDEA·IN_PROGRESS·DONE·DROPPED), `ErrorCode`에 `IDEA_ITEM_NOT_FOUND`·`IDEA_EMPTY_KEYWORD`·`IDEA_KEYWORD_TOO_LONG` |
| API | `IdeaController`: `POST /api/idea/create·list·recent·update·delete` |
| 화면 | `/ideas` > `pages/ideaPocket.html`, `static/js/ideaPocket.js`, 대시보드 빠른 입력 카드 `static/js/dashboard-idea.js` |
| DB | Flyway `V2_5_116__create_idea_item.sql` (`CREATE TABLE IF NOT EXISTS`) |

```mermaid
flowchart TD
    A[대시보드 키워드 입력 후 Enter] --> B[POST /api/idea/create]
    B --> C{키워드 검증}
    C -->|비었음| D[IDEA_EMPTY_KEYWORD 400]
    C -->|200자 초과| E[IDEA_KEYWORD_TOO_LONG 400]
    C -->|정상| F[상태 IDEA 로 저장]
    F --> G[최근 5개 카드 갱신]
    G --> H[/ideas 전체 보기]
    H --> I[검색 · 메모 수정 · 상태 변경 · 삭제]
```

## 왜 이렇게 했나

- 이슈에 세부 UI가 정해져 있지 않아 가장 단순한 형태로 만들었다: 키워드(필수)·메모(선택)·상태 4개.
- 상태 배지는 DaisyUI 시맨틱 색(IDEA neutral, 진행중 info, 완료 success, 보류 ghost)을 써서 다크모드에서도 그대로 보인다.
- 검색은 화면 안 필터로 처리했다. 개인 기록용이라 항목 수가 많지 않다.

## 하지 않은 것

태그·카테고리, 첨부파일·영상, 우선순위 정렬, 비로그인 공개, Task 목표로 바꾸기.
