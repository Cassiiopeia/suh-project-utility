# AI 서버 관리 페이지 진입 시 다운로드 상태 조회 500 오류

## 개요

AI 서버 관리 페이지에 들어가면 진행 중인 다운로드를 복원하려고 호출하는 `/api/ai-server/models/pull/status` 가 500 오류를 냈습니다. 이 API 는 POST 전용인데 페이지가 GET 으로 호출했고, 응답도 `downloadProgressMap` 필드로 오는데 다른 형식으로 읽고 있었습니다. 로컬뿐 아니라 프로덕션에서도 재현되던 기존 버그이며, 배포 커밋은 `d83b307` 입니다.

## 변경 사항

- `templates/pages/aiServer.html`: `restoreActiveDownloads` 가 POST(FormData)로 호출하도록 바꾸고, 응답의 `downloadProgressMap` 을 읽어 진행 중인 다운로드를 복원

## 검증

- 로컬: 페이지 진입 시 실패한 요청과 콘솔 오류 0건, 다운로드 상태 복원 로그가 `{}` 로 정상 출력
- 프로덕션 배포 후: `/ai-server` 실패 요청 0건, 콘솔 오류 0건

## 주의사항

- 이 API 는 프로젝트 규칙대로 POST 와 multipart 로 호출해야 합니다. 새로 호출을 추가할 때 GET 을 쓰지 마세요.
