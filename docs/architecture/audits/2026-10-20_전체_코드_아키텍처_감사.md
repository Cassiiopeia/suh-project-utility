# 아키텍처 감사: suh-project-utility (2026-10-20)

## 한 줄 결론
구조 규칙(@ManyToOne 전용, Flyway 가드, DaisyUI 토큰)은 잘 지켜졌지만, **입력 검증·권한·예외 변환 같은 경계 처리가 공통 지점 없이 화면·서비스마다 따로** 만들어져 보안 구멍과 실패 은폐가 쌓였다. 규칙 문서(CLAUDE.md)는 모듈 목록·CSP·null 체크 금지 등이 코드와 어긋나 강제력이 없다.
